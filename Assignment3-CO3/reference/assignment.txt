Bloom’s Level: K4 – Analyse
Problem Context – College Central Library
The library stores the accession numbers of its books in an array. Students search for a book by accession

Record comparisons for successful and unsuccessful searches
Plot comparisons against array size for both searches
Check whether the results agree with Student A’s predictions

If new books are added every day, is it still worth keeping the array sorted for binary search? What information 
would you need to decide?
Both students must be able to defend the answer.
